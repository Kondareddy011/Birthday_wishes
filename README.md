# ✨ Modern Premium 3D Birthday Wishes Website 🎂🎉

A personal birthday greeting web experience built with **React**, **Vite**, **Tailwind CSS**, **Three.js**, and **Web Audio API**.

---

## 🗺️ Multi-Page Journey & Special Surprises

The website is structured as a **6-Chapter Multi-Page Birthday Quest** where **every single page features branching options to advance to the next page and a unique interactive special surprise**:

| Chapter | Title | Options to Advance | Special Surprise |
| :--- | :--- | :--- | :--- |
| **Ch. 1** | **The Grand Welcome** | 🎁 Go to Gift Vault / 📸 Memory Lane / 🎆 Grand Finale | **Magic Wand & Cosmic Fortune Cookie 🥠**: Wave the magic wand to crack open a 3D fortune cookie revealing personalized lucky numbers & cosmic guardian. |
| **Ch. 2** | **The Mystery Vault** | 📸 Enter Memory Lane / 💌 Read Wishes / ⬅️ Back to Start | **Golden Scratch-Off Card 🎰**: Scratch 3 mystery foil spots to unlock exclusive VIP birthday perks with confetti bursts. |
| **Ch. 3** | **Polaroid Memory Lane** | 💌 Enter Wishes Hall / 🔮 Destiny Oracle / ⬅️ Back to Gift | **Friendship Time Capsule ⏳**: Locked vault opened with the celebrant's age passcode, revealing a Golden Trophy & throwback voice note. |
| **Ch. 4** | **The Wishes Hall** | 🔮 Consult AI Oracle / 🎆 Grand Finale / ⬅️ Back to Memories | **Floating Sky Lantern of Wishes 🏮**: Write a secret dream onto a sacred lantern and release it floating into the starlit night sky. |
| **Ch. 5** | **AI Destiny Oracle** | 🎆 Grand Finale / 💌 Back to Wishes / ⬅️ Back to Start | **3D Crystal Ball of Future Prophecy 🔮**: Rub the swirling mystical orb to gaze into your career, soul tribe, and wanderlust forecast. |
| **Ch. 6** | **Grand Finale Party Hall** | 🔗 Share Link / 🛡️ Host Admin / 🔄 Replay Quest from Ch. 1 | **Champagne Pop & Royal Certificate 🍾**: Pop the golden champagne bottle with flying cork, and print/download an official Certificate of Honor. |

## 🌟 Other Core Features

- **💫 Modern Premium 3D Design**: Three.js particle vortex & stars reacting to mouse parallax, glassmorphic frosted cards, glowing text, and 4 luxury theme palettes.
- **🎂 Interactive 3D Birthday Cake**: Flickering candles that blow out with smoke wisps and fanfare.
- **📸 Polaroid Photo Gallery**: Tilt physics, tags, and full-screen lightbox.
- **💌 Live Wishes Wall**: Emoji avatar picker, card aura styles, and live reaction counters (❤️, 🔥, 🥂).
- **🤖 AI Birthday Wish Studio**: Generates tailored messages across 6 tones (Heartfelt, Roast, Poetic, Hype, Rhyme, Short).
- **🔗 Shareable Link & Printable QR Code**: Encodes custom details in URL parameters for instant social sharing.
- **🛡️ PIN-Protected Host Admin Dashboard** (Default PIN: `1234`): Manage celebrant profile, themes, gifts, photos, and wishes.
- **🎶 Ambient Synthesizer**: Web Audio API generated offline "Happy Birthday" melody and SFX soundboard.
- **🎈 Floating Balloons**: Poppable balloons floating across the screen.

## 🚀 How to Run

1. **Install Dependencies**: `npm install`
2. **Start Dev Server**: `npm run dev`
3. **Production Build**: `npm run build`
4. **Access in Browser**: [http://127.0.0.1:5173](http://127.0.0.1:5173)
